## 사용법

1. 이 파일을 복사해 `README.md`로 저장한다.
2. `{{...}}` 를 전부 지우고 실제 내용으로 채운다.
3. 제목·소제목은 **한글만** 쓰고, (영문 부제) 같은 건 넣지 않아도 된다.
4. **기술 스택** 표는 프로젝트마다 구분 이름이 다르므로, 템플릿의 3행에 고정되지 않고 위 안내대로 바꾼다.
5. 구현 영상은 **GIF 한 장만** 두는 형태가 GitHub README에 잘 맞는다. (`<video>` 는 README에서 안 뜨는 경우가 많다.)
6. 도식 PNG는 `docs/`, 데모 GIF는 `img/` 에 두는 식으로 경로만 맞춘다.
